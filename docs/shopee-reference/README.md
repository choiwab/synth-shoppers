## Summary for the build agent

Build a pixel-faithful Shopee SG clone with these 8 screens/states:
1. **Home** (`/`) — orange header + hero banner + categories grid + flash deals
2. **Search results** (`/search?keyword=beanie`) — left filter sidebar + 5-col product grid + sort bar
3. **Product page** (`/shopee/:id`) — gallery + variant picker + price + ATC/Buy Now buttons
4. **Add-to-cart toast** — overlay on product page confirming add, cart badge increments
5. **Cart hover dropdown** — mini cart on header hover with "View My Shopping Cart"
6. **Cart page** (`/cart`) — full cart table, quantity controls, "Check Out" button
7. **Checkout page** (`/checkout`) — pre-filled address, order summary, shipping, "Place Order"
8. **Post-run reports** (`/report/:runId`) — Analytics / Recommendations / Viability tabs

**Matin Kim product page** must additionally expose `data-action` hooks for browser-use agents:
- `data-action="scroll-gallery"` — gallery scroll button
- `data-action="open-reviews"` — reviews toggle
- `data-action="select-variant"` — variant picker
- `data-action="add-to-cart"` — Add To Cart button
- `data-action="checkout"` — Check Out button on cart page
- `data-action="confirm-order"` — Place Order button on checkout page
- `data-gate="land|photos|reviews|price|cart|checkout"` — section wrappers
- `data-field="title|price|rating|review-count|seller-name"` — readable fields
